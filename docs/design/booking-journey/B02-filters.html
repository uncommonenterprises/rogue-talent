Design notes
  • One panel, two presentations. The same markup is the 272px sidebar from 900px and a full-height sheet below it. In the sheet the header carries "Clear all" and a 44px close button; the footer carries the single cobalt action, "Show N models". In the sidebar, results update as filters change and there is no footer button.
  • Groups collapse. On B01 the first three groups (categories, day rate, gender) start open and the rest are collapsed, each with a count badge when something is selected. Here every group is open so the full set can be reviewed.
  • Chips, not long lists. Categories, gender, experience, hair and eye colour are chips (rt-chip, selected = ink-900, not cobalt) at 44px tall on phones. Ethnicity and travel range are tick boxes with 44px rows because the lists are longer or the labels wrap.
  • Footer count. The button label follows the live result count. At zero it reads "No models match" as a disabled secondary button, with "Clear all" remaining in the header, so the client is never invited to apply a filter set that returns nothing.
  • No colour swatches for hair and eye colour: text labels are clearer and avoid inventing a colour palette outside the tokens.
  • Travel range changes meaning. The template filter is "equals one value", which would hide a National model from a client who ticks "Regional". The design assumes a multi-select, match-any filter (a Console setting, no code). Listed as a dependency.
  • Leaving the sheet. Esc and the close button dismiss the sheet without changing the results; "Show N models" is the only way to commit.
