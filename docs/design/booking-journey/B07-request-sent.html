Design notes
  • Answers three questions in this order: did it go through (title and status chip), what happens now (the 48-hour window with the actual deadline, "Tue 3 Nov, 16:20"), and what happens next (accept or decline, in plain terms). The deadline is real: the process expires a request at the earlier of 48 hours after payment authorisation and the start of the shoot, so the page can show it exactly. Nothing here is a promise about how quickly a model replies.
  • Where to track it. The one cobalt action is "Go to your bookings" (B09). The same page is reachable later from Your bookings and from the email, and then the top card is replaced by the status banner for whatever state it is in (B09), so the "just sent" celebration does not stick around.
  • Honest about money. "Nothing has been charged" and "Not charged unless Ava accepts" both appear; the amount is shown so the client knows what will be taken if Ava accepts.
  • No withdraw link. The current booking process has no way for a client to cancel before the model replies, so this page does not offer one. That is a gap worth closing before launch (open question 9).
  • Summary shows what was agreed: dates, shoot type, location type and address, and a link to the licence the client agreed to (the agreement is recorded at checkout). The shoot address is shown only to the client and the model.
  • Messages use the existing booking conversation. No promise about reply times appears anywhere.
