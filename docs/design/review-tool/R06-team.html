Design notes
  • Build timing (decided 07/11/2026): this page is built in stage 3. Until then the PM adds reviewers through Console. Every reviewer gets every submission email, and the first decision wins.
  • As small as it can be: one field, one button, one list. Nothing to learn. Only admins see this page and the "Team" link; a reviewer who opens it directly gets the plain "no access" page (R07).
  • One cobalt action: Add reviewer. Remove is secondary, not red: it is reversible in ten seconds by adding the person again, so it is not danger. It still asks once, inline, and says exactly what changes.
  • Adding needs an existing account, because reviewers use their own Rogue Talent log-in (as briefed). If there is no account, the error says what to do next. Inviting a brand-new person by email would be a larger build.
  • Admins cannot be removed from here, so the last admin can never lock everyone out. Who is an admin is set outside this page. Admins also see "Reopen review" on decided pages (R03); reviewers do not.
  • Removing someone does not delete their past decisions. The queue's "Recently decided" still shows who decided, so the record stays whole.
  • Addresses use the reserved example.com domain. Names are example data.
