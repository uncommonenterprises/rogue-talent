What a person sees when something is not the happy path. Each box below is a separate view.

Design notes
  • "You don't have access to this page" and nothing else, as asked. One heading, one way out. No "contact an admin", no mention of reviewers, no profile name. The action is the cobalt button because it is the only action on that view.
  • The first decision wins. Every reviewer is emailed, so two people will sometimes open the same person. The server must refuse the second decision, and the page tells them plainly, rather than silently overwriting or sending two emails. This is a build requirement, not only a design one.
  • Red is only for things that failed (decision not saved). Decided-by-someone-else when you only opened the page is information, so it uses the neutral notice.
  • A made-up link and a real one look the same to people without access. Do not use different wording for "doesn't exist" and "not allowed".
