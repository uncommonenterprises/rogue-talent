Design notes
  • This is the model's dashboard/profile home while Pending. The amber rt-status badge appears both in the top nav (compact) and large on the card, per the badge spec's placement guidance.
  • The "verify now" callout is the one cobalt action on this page: there's genuinely nothing else actionable to do while waiting, so it's safe to make it primary rather than secondary.
  • The alternate state (already-verified-while-pending) swaps the callout for a small green subnote instead of repeating the "verify now" prompt, per lifecycle spec §7, so an early verifier isn't confused by a call to action for something they've already done.
  • No invented review-time estimate ("usually 2 days" etc.). We don't have real data yet to back a number.
  • RT-FB-10 (Neil, 28/09): "availability" is removed from the submitted checklist (there's no onboarding availability step any more), and a quiet "Manage your calendar" link is added, deliberately understated (a plain text link, not a button) since it's entirely optional. Copy is explicit that models are available by default and still confirm every booking request themselves, so this never reads as something they forgot to do.
