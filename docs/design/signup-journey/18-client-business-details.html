Design notes
  • The sign-up/step-2 split, and why: company name stays on the sign-up form (screen 03) because it's identity-defining and low-friction to type. Everything else (registration number, industry, project types, website, VAT) moves here, after email verification, following the same progressive-disclosure principle as the model wizard: get the account created fast, ask for more once someone's committed.
  • Open question for Neil/Developer: today's config (configUser.js) has company_registration_number set to displayInSignUp: true, i.e. it currently shows on the sign-up form. Building this design means flipping that to false and adding this new step instead, a real config change, not just a visual one.
  • Registration number is the only required field here. It's the one thing Gate A's Companies House check actually depends on; everything else is enrichment and stays optional, matching every other client field's existing convention.
  • "Submit for approval" on this screen doubles as the client's Gate-A submission (there's no separate client "review" screen in this journey, unlike the model's 4-step wizard, since there's much less to review).
