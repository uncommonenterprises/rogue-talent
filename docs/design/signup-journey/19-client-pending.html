Design notes
  • Mirrors the model's Pending screen (14) structurally, so the pattern is learned once and recognised on both sides. Only the tracker step copy and reviewer detail (Companies House vs portfolio quality) differ.
  • Browsing is allowed while Pending (there's no reason to block discovery), but it's a secondary action. Booking is the gated capability, not browsing, so the copy is precise about what "not yet bookable" actually means.
  • Revision 3 (Neil, 29/09): replaced the info-list checklist with the same vertical progress tracker pattern as screen 14: 1 Submitted (done), 2 Business check by our team (current, "In progress"), 3 Verify your identity (to do), 4 Ready to book (to do). Done, current and to-do are distinguished by fill/border colour and the explicit status label, never by an empty vs filled circle.
  • Revision 3 (Neil, 29/09): the "you can browse but not book yet" message is now one short plain sentence under the tracker, rather than a checklist item.
  • Same banked-verification tracker state as screen 14 would apply here if verified early (step 3 done while step 2 is still current). Omitted from this file to avoid repeating it a third time; see screen 14's alternate state for the full treatment.
