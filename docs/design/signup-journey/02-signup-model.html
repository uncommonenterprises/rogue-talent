Design notes
  • Date of birth is gone (RT-FB-03, agreed 28/09): replaced with a plain "I confirm I'm 18 or over" tick box. Self-declared DOB gave no real protection over a tick, and the actual safeguard is the ID-verified 18+ check at Stripe verification (SAF-38). This supersedes the earlier dob-field-spec.md.
  • Terms/privacy and the age confirmation are two separate tick boxes rather than one combined line, so each can carry its own validation error without a confusing compound message.
  • Fields match what's actually collected today (configUser.js): first/last name, email, password, optional phone. Display name isn't asked here. It's set from first name + last initial on the first onboarding step, editable there.
  • One primary action (cobalt) on the page: "Create my model account". Google sign-in stays secondary/outline, consistent with the existing social auth pattern.
  • The ink panel's claims are checkable today: 100% of rate, clients ID-verified before booking (Gate B, account-status-lifecycle spec), manual profile review (Gate A). Nothing about response times or member counts.
