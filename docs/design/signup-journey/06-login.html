Design notes
  • Same split-shell frame as sign-up for one consistent auth system, but the panel copy is role-neutral (login doesn't know who's arriving). Warm and simple rather than a value pitch.
  • "Forgot your password?" sits as a hint directly under the password field, not buried below the button - one glance, not a hunt.
  • Only one primary (cobalt) action on the page: Log in. Google sign-in is secondary; both sign-up links are text links, not competing buttons.
  • Mobile pass (29/09/2026): below 900px the ink panel collapses to a slim header bar (brand + "Welcome back" only), so this form now starts near the top of the screen. The panel footer's "New here? Create an account" link is duplicated under the form, next to "Don't have an account?", which already pointed the same way - both are shown so the phrasing from the panel isn't lost either.
