Design notes
  • This is the already-agreed RT-FB-06 rework, carried into the new split layout: one headline with the name, one line showing the address, one clear primary button, one quiet help line. No stock fern background, no stray small print at the bottom.
  • The primary button changes by role, since "what's next" genuinely differs. Shown below for both. This mockup defaults to the model variant above; the client variant is the second card.
  • Resend / wrong-email / spam guidance stays merged into one quiet line under the button rather than three separate prompts. Typos and spam are the two real reasons verification fails, so it's kept, just de-emphasised.
