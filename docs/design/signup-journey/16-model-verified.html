Design notes
  • Celebratory but restrained per the brand voice: no confetti, no gradients, no exclamation marks. A green status chip, a clean checkmark, and a plain headline ("You're live.") does the work.
  • One primary cobalt action ("View your live profile"); copying the link and managing the calendar are both quieter, so the page doesn't compete with itself.
  • No per-profile public "Verified" badge is shown elsewhere in the product any more (retired per lifecycle spec §9: every visible model is verified by definition, so a badge on every card would be redundant). This screen is the one place "Verified" is meaningfully news, because it's the model's own status changing.
  • RT-FB-10 (Neil, 28/09): the old "Set your availability" button is replaced with a quiet "Manage your calendar" text link, matching screen 14's treatment, since blocking dates is now entirely optional maintenance, not an onboarding task. Copy is explicit that the model is available by default and still confirms every booking request themselves.
