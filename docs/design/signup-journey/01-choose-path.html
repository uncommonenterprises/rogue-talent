Design notes
  • Two role cards replace the old "User type" dropdown (RT-FB-01). The choice is the first thing a visitor makes, with no empty gap while a role is unpicked.
  • Split layout: the ink panel carries the value proposition so the choice itself stays uncluttered. No stock photography anywhere in this journey. See the portfolio step for where real photography belongs.
  • Cards use a hairline border with a cobalt hover state, not a filled cobalt background. They're navigation, not a competing primary action, so "one cobalt action per view" still holds.
  • Copy only uses facts we can stand behind today: 100% of rate to the model, one flat 15% fee, manual review on both sides. No invented member counts or booking volumes (RT-FB-09).
