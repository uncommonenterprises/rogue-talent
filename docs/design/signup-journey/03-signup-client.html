Design notes
  • This screen carries the one inline validation-error example for the pair of sign-up forms: a mistyped email domain ("gmial.com"), shown in the rt-input--error state with the matching rt-field__error message. Illustrative only, not the default state.
  • Decided by Neil, 29/09: company name is collected here, but company registration number (and industry/website) move to a dedicated "Your business details" step after email verification (screen 18) rather than sitting on the sign-up form, to keep this first screen fast. This split is approved.
  • Same 18+ tick box and terms/privacy pattern as the model form, for consistency across both sign-up variants.
  • Revision 3 (Neil, 29/09): phone number is removed from this form (PM decision: we don't use it at sign-up). The client's phone moves to "Business phone number" on the new Your business details step (screen 18), where it belongs alongside the rest of the business information.
  • Revision 3 (Neil, 29/09): fixed the same terms/privacy spacing bug as screen 02 - the label text and its links are now wrapped in a single <span> so .rt-check's flex gap doesn't put a visible gap between every word and link.
  • Revision 3 (Neil, 29/09): with phone removed, the form uses the same .form-card--compact tightened spacing as screen 02, so it fits a typical ~800px-tall laptop viewport without scrolling.
